# u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162

One-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty ($2 in USDC). The program writes a single joke about office life to `/output/entry.txt`.

The joke: a manager tells the narrator to "take more ownership" in a performance review, and the narrator complies in the most literal way possible — by taking the office's good chair home.

## Run it

```sh
node main.ts
```

It writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
